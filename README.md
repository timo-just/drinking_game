# RUNDUM

28 Minispiele für ein gemeinsames Handy. Öffne https://timo-just.github.io/drinking_game/ .

Statische App: index.html, style.css und app.js. Keine Installation oder Registrierung. Spielerliste wird nur lokal gespeichert.

Die Spiele lassen sich einzeln oder nacheinander testen. Sensoren und Multitouch hängen vom Handy und Browser ab. Körperliche Aufgaben und Schere-Stein-Papier werden von der Gruppe gewertet.
